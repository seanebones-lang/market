## Implemented contract

The engine now calculates descriptive statistics for the strategy, cash, matched-notional
buy-and-hold, and periodic DCA from their complete costed net-liquidation-value series. Strategy
statistics use an unsampled internal observation at every approved hourly close, regardless of the
display-equity sampling setting.

Every return is a simple NLV return. The first compares the first hourly close with starting cash;
later returns compare adjacent closes. All four portfolios share:

```text
observation frequency         = hourly bar close
period seconds                = 3,600
crypto periods per year       = 8,760
risk-free annual assumption   = 0%
volatility estimator          = sample standard deviation, n - 1 denominator
annualization                 = sqrt(8,760) for volatility, Sharpe, and Sortino
```

Downside deviation is the square root of the mean squared negative simple return across all
periods. Zero variance, no downside returns, insufficient observations, no closed trades, no losing
trades, zero starting cash, and zero benchmark variance all produce explicit statuses instead of
invented values.

## Metric definitions

| Metric | Exact definition |
|---|---|
| Turnover | Gross absolute executed notional divided by arithmetic mean NLV over starting cash plus all closes |
| Exposure | Percentage of bar-close observations with positive BTC inventory |
| Drawdown duration | Consecutive closes below the preceding costed-NLV peak |
| Profit factor | Positive fee-aware closed-trade P&L divided by absolute negative fee-aware closed-trade P&L |
| Expectancy | Mean fee-aware net P&L per closed trade |
| Explicit fee drag | Explicit transaction fees divided by starting cash, in return percentage points |
| Benchmark alpha | Hourly OLS intercept of strategy returns on aligned benchmark returns, multiplied by 8,760 |

Explicit fee drag does not relabel synthetic spread or adverse slippage as a fee. Alpha is an
arithmetic fractional return, not a confidence-qualified inference.

## Hand-calculated portfolio proof

The golden series starts with `$100` and has hourly NLV observations of `$100`, `$110`, and `$99`.
Its simple returns are exactly `0`, `+0.1`, and `-0.1`.

```text
sample mean hourly return       = 0
sample hourly volatility        = sqrt((0^2 + 0.1^2 + -0.1^2) / (3 - 1)) = 0.1
annualized volatility           = 0.1 * sqrt(8,760)
annualized Sharpe               = 0
downside deviation              = sqrt(0.1^2 / 3)
annualized Sortino              = 0
maximum drawdown                = $11 / 10%
maximum/current duration        = 1 bar / 3,600 seconds
```

One of three closes has positive inventory, so exposure is `100 / 3%`. Two fills execute `$10` and
`$12`; average NLV across `$100` starting cash plus the three closes is `$102.25`, so turnover is
`22 / 102.25`. Fee-aware closed trades of `+$3` and `-$1` produce profit factor `3` and `$1`
expectancy. `$2` of explicit fees on `$100` produces two return percentage points of fee drag.

## Hand-calculated alpha proof

The regression fixture uses benchmark hourly returns `0.01`, `-0.01`, and `0.02`, with strategy
returns defined exactly as:

```text
strategy return = 0.01 + 2 * benchmark return
```

The analyzer recovers beta `2`, hourly alpha `0.01`, and annualized alpha `87.60` exactly. A cash
series has zero benchmark-return variance, so its beta and OLS alpha are explicitly undefined while
the annualized active-return difference remains available.

## Failure-path coverage

- Missing portfolio names, invalid annualization periods, negative/non-finite capital, unordered or
  invalid observations, and negative/non-finite inventory fail closed.
- Fill fees must reconcile exactly to cumulative explicit fees.
- Closed-trade P&L must be finite.
- Strategy and benchmark alpha series must have equal length and identical timestamps.
- Zero/negative previous portfolio values do not produce fabricated returns.
- Zero variance, no downside, insufficient observations, no trades, no losses, zero capital, and
  zero benchmark variance have deterministic status coverage.
- Downsampling the display equity curve cannot downsample the statistic input series.
