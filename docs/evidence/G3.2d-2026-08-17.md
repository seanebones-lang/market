## Outcome

The repository now freezes how a future 30-day Robinhood v2 route-cost corpus must be scheduled,
admitted, summarized, uncertainty-qualified, and mapped into candidate research-engine inputs.
Those decisions were made before any real cost observation exists.

The analyzer operates only on local G3.2c evidence bundles. It does not collect data. It verifies
the complete corpus, measures missingness against the frozen schedule, withholds cost profiles when
coverage fails, computes deterministic exact-Decimal distributions and daily-block bootstrap
intervals when coverage passes, and writes an immutable summary whose ID binds both its content and
every observation identity.

This is study-design readiness, not empirical cost evidence. There is no production run plan and
therefore no authorized collection window.

## Corpus behavior proved

The tests use a compressed synthetic-only protocol with two UTC dates, four scheduled cycles, two
quantities, eight observation bindings, and 19 bootstrap replicates. That fixture is deliberately
different from the production source-kind and duration so it cannot be mistaken for a production
run.

The admitted synthetic case proves:

- all G3.2c bundles are reverified before aggregation;
- reversing manifest input order produces the identical typed analysis and summary ID;
- four complete cycles produce 100% overall coverage;
- distributions for both quantities use the same four timestamps;
- maximum observed fee maps to the candidate per-fill fee;
- p75 and p95 map to base and stress component choices;
- the worse nonnegative directional size impact is used;
- 10/20-bps unmeasured-execution buffers remain explicit;
- daily-block interval bounds contain the observed golden quantile;
- eight observation bindings are preserved with manifest and observation hashes;
- the immutable summary bundle reopens and verifies; and
- a second write to the same content-addressed directory is refused.

The failure tests prove:

- unknown protocol choices fail strict schema validation;
- intervals that do not divide a UTC day fail;
- a run plan cannot start at a later intraday slot;
- a run plan cannot predate its protocol;
- a changed protocol hash invalidates the run plan;
- one missing quantity makes its cycle partial and removes it from every distribution;
- insufficient coverage preserves a failed summary but emits no base or stress profile;
- a synthetic observation is rejected under a captured-read-only production source contract;
- duplicate observation IDs fail;
- quantity observations with different books cannot claim one capture cycle;
- observations outside the fixed window fail;
- modified summary bytes fail manifest verification; and
- even if an attacker updates the summary hash and byte count, changing valid summary content fails
  the recomputed content-addressed study ID.

## Cost mapping boundary

An admitted production corpus would produce candidate backtest inputs at the primary quantity:

```text
fee per fill = maximum observed fee bps
full spread = p75 or p95 displayed full-spread bps
size impact = max(0, buy quantile, sell quantile)
adverse slippage = size impact + explicit 10 or 20 bps buffer
```

The analyzer also reports an additive round-trip diagnostic. It does not call that diagnostic the
engine's exact multiplicative return, and it does not automatically modify a strategy protocol or
backtest configuration.

Every mapped profile is labeled
`candidate_research_input_not_execution_evidence`. The production configuration requires
`captured_read_only_v2`; synthetic fixtures cannot generate a production profile.

## CLI boundary

Three commands were added:

```text
freeze-rh-v2-cost-run
summarize-rh-v2-cost-study
verify-rh-v2-cost-study
```

All identify themselves as offline. The run-plan command writes a dated contract but performs no
collection. The summarize command reads local manifests, and the verify command reads local
summary files. None imports or invokes a broker transport. Console output explicitly reports no
network contact, credential creation, collection, execution, or strategy result as applicable.

The summarizer returns nonzero after preserving failure evidence when corpus coverage does not
pass.
